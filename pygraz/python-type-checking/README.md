# Python type checking

This is a talk given at the [Python user group Graz](https://pygraz.org) on 2026-09-01.

It gives an introduction to Python type hints including a few non-trivial cases like forward references and generators. It also shows how type checkers like `ty` can be used to enforce typing as static check.

In conclusion, Python type hints can be helpful to create better code, but are still a moving target and have some idiosyncrasies.
